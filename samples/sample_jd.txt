Job Title: Full Stack Software Engineer

Company: Horizon Technologies

Job Description:
We are looking for a skilled Full Stack Software Engineer to join our growing
engineering team. The ideal candidate will have strong experience building
scalable web applications and working across the full technology stack.

Required Skills:
- Strong programming skills in Python and Java
- Experience with React and Node.js for front-end and back-end development
- Familiarity with Django or Flask frameworks
- Experience with REST API design and development
- Knowledge of MySQL and PostgreSQL databases
- Experience with Git and GitHub for version control
- Understanding of Docker and cloud platforms such as AWS or Azure
- Familiarity with Kubernetes is a plus
- Solid understanding of Data Structures and Algorithms
- Experience working in Agile and Scrum environments
- Exposure to Machine Learning concepts is a plus
- Strong Communication and Teamwork skills
- Good Problem Solving and Leadership abilities
- Experience with TypeScript and GraphQL is a plus

Responsibilities:
- Design, develop, and maintain scalable web applications.
- Collaborate with cross-functional teams in an Agile environment.
- Write clean, maintainable, and well-tested code.
- Participate in code reviews and mentor junior developers.

Qualifications:
- Bachelor's degree in Computer Science or related field.
- 2+ years of relevant software development experience.
